# fossil-ai-systems

The FOSSIL knowledge pack for AI systems and agents, coding and research
harness design, Codex/Claude and other coding-agent workflows, model and
retrieval research, orchestration and verification patterns, and KEDB-style
failure knowledge.

This pack applies provenance and citation methodology from `fossil-common`.
Model agreement is metadata, not external evidence. The pack is identified by
the stable logical ID `pack_f024177f89a5442db84171c3dd7f58e5`; this repository is
physical placement only.

The pack may read shared methodology from
[`fossil-common`](https://github.com/Pukujan/fossil-common), while AI-system
knowledge is written locally. Reusable knowledge moves upward only through
explicit promotion events that preserve provenance. Graphiti, Neo4j, and
other graph or search representations are rebuildable projections under the
FOSSIL/DICS contracts.

The `dkg.pack.v1` manifest is derived from the canonical seed in
[`fossil-core`](https://github.com/Pukujan/fossil-core/blob/main/examples/packs/plugin-harness/manifest.json).
Contract and policy versions remain owned by fossil-core rather than being
silently forked here.
